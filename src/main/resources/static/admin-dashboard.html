Historical Attendance CSV Import

Import past attendance logs in batch with validation against registered students, classes, and subjects.

CSV File Format Specifications

Your CSV file must contain the following required header columns:

USN,SubjectCode,SubjectName,Semester,Section,Date,Session,Status,TeacherID
  • Date: Format YYYY-MM-DD (e.g. 2026-09-15)
  • Status: PRESENT, ABSENT, LATE, or EXCUSED
  • Session: Session slot number (e.g. 1, 2)
  • TeacherID: Faculty Employee ID or system ID (optional)
